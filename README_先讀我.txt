東涌影像檔案：這次更新只需替換網頁，毋須重新下載地圖或照片。

安裝（Mac）
1. 先把目前的 index.html 複製一份備份到網站資料夾外。
2. 將本包內 index.html、stories.html、Start_Local.command、start_preview.py 四個檔案，放進原本網站資料夾。
   這四個檔案應與 data、images、tiles、css、js 資料夾並列。
3. 同名 index.html 選「取代」。其餘現有資料夾全部留在原位；本更新沒有 tiles、images 或 data 資料夾需要取代。
4. Safari：照舊打開 index.html。開站預設仍是 OpenStreetMap。
5. Chrome：請使用 Start_Local.command 開啟，保持啟動後的終端機視窗開著。
   若提示沒有執行權限：開啟「終端機」，輸入 bash 和一個空格，然後把 Start_Local.command 拖進該視窗，按 Return。
   若找不到 Python 3，保留錯誤訊息並告訴我；啟動檔會先尋找既有 Python 或 QGIS 內附的 Python，不會自動安裝。
6. 結束預覽後，可在終端機按 Control+C 停止。只監聽本機127.0.0.1，不會把網站公開上網。
